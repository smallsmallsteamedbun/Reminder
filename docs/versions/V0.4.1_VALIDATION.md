- 结论：固定间隔输入优化与持久化边界验证通过

## 本版本范围

- 固定间隔内部继续使用总分钟数，界面按照合法总时长动态显示分钟、小时和天输入框。
- 小于 60 分钟时只显示分钟；达到 60 分钟后显示小时；达到 24 小时后显示天；最大间隔为 365 天。
- 各时间分量支持自动进位，确认后规范化为天、小时和分钟。
- 在分量输入框之间移动焦点时不提交；按下 Enter 或焦点离开整个固定间隔区域时才统一校验和重排。
- 单个空分量按 0 参与整组换算；其余分量合计合法时正常应用，全部为空或合计为 0 时拒绝应用。
- 非法界面草稿不修改事件逻辑状态，也不会进入即时保存或约一小时低频存档。
