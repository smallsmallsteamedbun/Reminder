# Reminder `0.3.0` 验证记录

- 验证日期：2026-07-27
- 版本：`0.3.0`
- 结论：通过

## 本版本范围

- 单项暂停、全部暂停和 Windows 系统状态采用相互独立的运行状态。
- 全部暂停支持手动恢复及 1 分钟至 5 小时的快捷时长，并显示限时暂停倒计时。
- 固定时间事件接入息屏和锁屏期间的继续、重新与暂停计时策略。
- 指定时间事件接入息屏和锁屏期间的提醒或不提醒策略。
- 实际睡眠和休眠期间统一抑制普通提醒，唤醒后汇总错过事件。
- 错过事件按事件去重汇总，并正确扣减终止次数及关闭已经结束的一次性事件。
- 未处理通知遇到锁屏或睡眠时按照延迟处理。
- 通知状态在启动时主动检查，并在界面右下角显示当前状态和故障说明。
- 托盘与主界面的全部暂停、全部恢复和全部重启行为按已开启事件统一处理。

## 验证结果

- `Debug` 与 `Release` 构建均通过，结果为 0 个警告、0 个错误。
- 25 项不可提醒状态自动化测试全部通过。
- 原有 18 项时间模型与通知操作回归测试全部通过。
- 默认窗口、窄窗口、固定时间表单、指定时间表单和限时全部暂停区域通过界面检查。
- Windows 通知状态、短时显示请求和系统状态监测器通过专项检查。
- 未发现乱码、明显遮挡、默认宽度横向溢出或持续运行的多余动画与轮询。

## 当前阶段限制

- 真实锁屏、显示器关闭、睡眠和唤醒行为仍受 Windows 设置、硬件与驱动影响，需要继续在普通桌面环境中体验复核。
- 数据保存、启动恢复、完整退出、主页与多页面导航、设置页、主题切换、版本检查、自动更新和正式安装包尚未实现。
- `docs/HOME_PAGE_DESIGN.md` 中的主页设计已经确认，但不属于 `0.3.0` 的已实现功能。
