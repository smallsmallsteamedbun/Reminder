## 版本范围

- 建立“主页、事件、设置”三个顶级页面，并把原有事件列表迁入独立事件页。
- 主页展示大型圆形倒计时、秒/分/时/天圆环和最多三个最近事件。
- 支持卡片悬停预览、圆形与卡片点击定位、稳定排序、固定卡片槽位和无运行事件状态。
- 设置页实现软件兼容渲染与硬件优先渲染、即时保存、重启提示、立即重启和稍后生效。
- 优化主页漂浮层次、页面切换、圆环回弹和共享全局按钮稳定性。
- 更新全部下拉框及展开菜单的视觉和滚动体验，并加宽终止次数控件。

## 资源验证

- 软件渲染模式下，主页可见工作集在当前设备约为 `176–180 MB`，窗口隐藏并完成回收后约为 `18–24 MB`。
- 硬件优先模式在当前设备仍出现约 `1.09 GB` 工作集；该结果尚不能代表其他显卡和驱动环境。
- 两种模式在页面交互期间都会出现短时 CPU 上升；窗口空闲和隐藏后的采样仍符合当前弹性目标。
- 详细测量与用户普通桌面复测见 `docs/versions/NEXT_STAGE_HOME_NAVIGATION_VALIDATION.md`。

## 已知限制与后续验证

- 软件渲染在当前设备上能够显著降低内存，但交互流畅度低于硬件优先模式。
- 硬件优先模式仍需在其他电脑和显卡环境上进行对照测试。
- 真实锁屏黑屏、实际睡眠、关机保存、超过一小时低频保存和未来安装目录写权限仍需继续实机验证。
- 当前尚未实现主题切换、开机自动启动、静默启动、通知时间设置、事件搜索、版本检查、自动更新和正式安装程序。
