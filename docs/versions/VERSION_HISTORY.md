# Reminder 版本更新记录

## 0.4.1 - 2026-07-28

- 固定间隔会根据总时长自动显示分钟、小时和天输入框，最长支持 365 天。
- 天、小时和分钟支持自动进位，确认后会重新整理为更易读的规范时间。
- 在输入框之间切换时保持当前编辑状态，按下 Enter 或离开整个间隔区域后再统一应用。
- 单个时间分量留空时按 0 处理，只要其余分量仍能组成合法间隔即可正常保存。
- 加强固定间隔输入校验；非法输入不会修改事件，也不会进入即时保存或定时存档。

## 0.4.0 - 2026-07-27

- 新增事件和运行状态保存，重新启动程序后可以恢复事件配置、倒计时和暂停状态。
- 完善离线恢复规则，固定间隔计时离线冻结，指定时间事件在离线期间错过后按规则汇总提示。
- 新增受保护的非明文状态文件、自动备份回退和恢复失败提示。
- 系统托盘新增完整退出流程，退出前保存最新状态；关闭主窗口仍继续后台运行。
- 新建、删除或修改事件后立即后台保存；全部暂停、全部恢复、全部重启和暂停时长修改后也会立即保存。
- 正常运行期间继续约每小时保存一次检查点，兼顾异常恢复和较低磁盘占用。

## 0.3.0 - 2026-07-27

- 新增限时全部暂停，支持手动恢复以及 1 分钟至 5 小时的快捷时长，并显示暂停剩余时间。
- 完善全部暂停、全部恢复和全部重启操作，统一处理所有已开启事件。
- 正式接入息屏、锁屏、睡眠和唤醒状态，并按每个事件的设置继续、重启、暂停或记录错过提醒。
- 新增“已跳过”汇总通知，同一事件多次错过只汇总一次，并正确处理终止次数和一次性事件。
- 优化锁屏和息屏期间的通知处理；未处理提醒遇到锁屏或睡眠时自动延迟。
- 新增 Windows 通知可用状态提示，启动时即可检查通知设置，异常状态会标红并提供解决说明。
- 托盘菜单新增快捷全部暂停和全部恢复，并优化全局按钮、暂停时长和通知状态的界面布局。

## 0.2.0 - 2026-07-24

- 新增指定时间事件，支持仅一次、每天、每周、每月和每年提醒。
- 新增“不终止”或 1–100 次的终止次数，并在完成或跳过后自动扣减。
- 完善事件类型切换、动态日期时间表单和输入合法性检查。
- 优化事件开启、关闭和暂停逻辑，指定时间事件不再显示无意义的暂停与重启操作。
- 改进事件卡片布局、长名称显示、运行状态颜色、滚轮与触摸板操作。
- 优化界面动画，使滚动、定位、删除重排和开关切换适应不同屏幕刷新率。
- 加入息屏和锁屏策略的设置界面；实际系统状态处理将在后续阶段接入。

## 0.1.1 - 2026-07-24

- 优化事件列表滚动与新建事件自动定位，使移动过程更加平滑自然。
- 删除事件前增加确认提示，并使用明确的红色危险操作样式。
- 删除事件后，下方事件卡片会平滑上移填补空位。
- 通知中心中的提醒可以通过点击正文重新展示操作按钮。
- 将版本号移动到主页左上角的程序名称旁。

## 0.1.0 - 2026-07-24

- 实现固定间隔事件的添加、编辑、删除、倒计时、暂停、恢复和重启。
- 支持关闭主窗口后继续后台提醒，并可通过系统托盘重新打开。
- 接入带“完成”“延迟”“跳过本次”的 Windows 通知。
- 未处理的通知横幅消失后继续保留在 Windows 通知中心。
- 事件列表支持鼠标滚轮，新建事件会自动定位并高亮。
- 优化短间隔事件的延迟时长，并补充输入合法性检查。
