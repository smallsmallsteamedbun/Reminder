# Reminder 版本更新记录

## 0.2.0 - 2026-07-24

- 新增指定时间事件，支持仅一次、每天、每周、每月和每年提醒。
- 新增“不终止”或 1–100 次的终止次数，并在完成或跳过后自动扣减。
- 完善事件类型切换、动态日期时间表单和输入合法性检查。
- 优化事件开启、关闭和暂停逻辑，指定时间事件不再显示无意义的暂停与重启操作。
- 改进事件卡片布局、长名称显示、运行状态颜色、滚轮与触摸板操作。
- 优化界面动画，使滚动、定位、删除重排和开关切换适应不同屏幕刷新率。
- 加入息屏和锁屏策略的设置界面；实际系统状态处理将在后续阶段接入。

## 0.1.1 - 2026-07-24

- 优化事件列表滚动与新建事件自动定位，使移动过程更加平滑自然。
- 删除事件前增加确认提示，并使用明确的红色危险操作样式。
- 删除事件后，下方事件卡片会平滑上移填补空位。
- 通知中心中的提醒可以通过点击正文重新展示操作按钮。
- 将版本号移动到主页左上角的程序名称旁。

## 0.1.0 - 2026-07-24

- 实现固定间隔事件的添加、编辑、删除、倒计时、暂停、恢复和重启。
- 支持关闭主窗口后继续后台提醒，并可通过系统托盘重新打开。
- 接入带“完成”“延迟”“跳过本次”的 Windows 通知。
- 未处理的通知横幅消失后继续保留在 Windows 通知中心。
- 事件列表支持鼠标滚轮，新建事件会自动定位并高亮。
- 优化短间隔事件的延迟时长，并补充输入合法性检查。
