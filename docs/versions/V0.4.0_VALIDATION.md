# Reminder `0.4.0` 验证记录

- 验证日期：2026-07-27
- 版本：`0.4.0`
- 发布状态：版本记录已完成，等待用户自行提交或上传
- 结论：持久化与生命周期阶段验证通过

## 实现范围

- 保存事件顺序、内部 ID、名称、事件类型、计划配置、终止次数、开关、暂停、系统状态策略和恢复所需计时状态。
- 固定间隔、延迟倒计时和限时全部暂停在程序离线期间冻结。
- 指定时间事件在离线期间按既有规则汇总错过并继续未来计划。
- 状态位于程序目录下的相对 `Data` 文件夹，不依赖当前工作目录。
- 状态采用版本化 JSON、Windows DPAPI 当前用户保护、临时文件、原子替换和上一份状态备份。
- `state.dat` 无法载入时自动尝试 `state.bak`；两者都失败时显示独立的恢复失败窗口。
- 新建、删除或成功修改事件配置后立即请求后台保存；紧邻请求可以合并，但始终保存最新完整状态。
- 全部暂停、全部恢复和全部重启完成后同样立即请求后台保存。
- 设置或更改全部暂停限时时长后同样立即请求后台保存。
- 正常运行约每小时低频保存一次；托盘主动退出和 Windows 会话结束时执行最终保存。
- 主窗口关闭继续隐藏到后台，只有托盘“退出”执行完整保存和进程关闭。

## 自动化验证

- 新增 13 项持久化与恢复测试，全部通过：
  - 新建事件、修改事件设置和删除事件分别触发即时后台保存；
  - 全部暂停、限时时长修改、全部恢复和全部重启分别触发即时后台保存；
  - 状态往返、事件顺序和内部 ID；
  - 状态文件不含事件名称明文；
  - 正式状态损坏后的备份回退；
  - 正式状态与备份同时损坏；
  - 临时文件不会被当作有效状态；
  - 固定间隔和限时全部暂停的离线冻结；
  - 延迟中的指定时间事件离线冻结；
  - 退出时未处理通知在恢复后汇总一次；
  - 一次性指定时间事件离线错过并关闭；
  - 循环指定时间事件离线错过多次只扣减一次；
  - 无效状态导入保持原有运行状态不变。
- 原有 18 项时间模型与通知操作测试全部通过。
- 原有 25 项不可提醒状态测试全部通过。
- Windows 活动监测器冒烟测试通过。
- 首次启动保存后再次启动能够恢复原有两个默认事件，不会重复创建。
- 主窗口、托盘“退出”、最终保存和显式关闭进程的真实应用冒烟测试通过。
