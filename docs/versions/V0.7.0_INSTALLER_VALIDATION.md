- 可以静默安装到 D 盘隔离目录，未要求目标电脑预先安装 .NET。
- 创建相对 `Data` 与 `Data\Updates`。
- 创建当前用户开始菜单快捷方式和卸载注册。
- 安装后的 `Reminder.App.exe` 能够正常启动并保持运行。
- Reminder 运行时再次执行安装，安装器能够通过单实例互斥体阻止直接覆盖，并提示用户先从托盘退出。
- 使用同版本安装器覆盖安装后，既有 `Data` 测试文件保持不变。

## 卸载验证

- “保留 Data”路径通过：程序文件、卸载器、开始菜单快捷方式和卸载注册被移除，完整 `Data` 目录继续保留。

- “删除 Data”路径通过：程序文件和完整 `Data` 目录均被删除，空的安装根目录同步清理。
- 当前用户的 `Reminder` 开机启动注册值会在卸载时清理。
- 无人值守卸载默认保留数据；显式 `/DELETEDATA=1` 时删除数据。

## 管理员安装

- 管理员安装模式正确写入 HKLM 卸载注册，并创建全局开始菜单快捷方式。
- 普通用户可以写入 `Data`，程序目录中的其余文件不因安装器规则获得普通用户修改权限。
- 管理员模式卸载能够移除全局快捷方式、HKLM 卸载注册、程序文件和选择删除的 `Data`。
