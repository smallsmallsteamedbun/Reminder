# Reminder `0.2.0` 验证记录

- 验证日期：2026-07-24
- 版本：`0.2.0`
- 结论：通过

## 本版本范围

- 固定时间事件和指定时间事件共用事件结构、倒计时、通知处理和最近到期调度。
- 指定时间事件支持仅一次、每天、每周、每月和每年。
- 固定时间事件及可循环指定时间事件支持“不终止”或 1–100 次。
- 指定时间表单使用独立的年、月、日、时、分输入框，并执行字段和组合日期校验。
- 事件卡片完成类型分段选择、启停联动、滚轮与触摸板输入、开关动画和紧凑布局优化。

## 验证结果

- `Debug` 与 `Release` 构建均通过，结果为 0 个警告、0 个错误。
- 应用页面、项目元数据和需求文档显示版本均为 `0.2.0`；程序集版本和文件版本均为 `0.2.0.0`。
- 18 项时间调度自动化测试全部通过，覆盖跨日、跨月、闰年、缺失日期、过去时间、终止次数和通知操作。
- 默认窗口与 760 像素宽窄窗口通过渲染检查；窄窗口仍保留横向滚动，滚轮和触摸板输入路由正常。
- 仅一次、每天、每周、每月、每年五种指定时间表单均通过动态布局和行为探针检查。
- 中文与英文长事件名称、终止次数下拉列表滚动、页面滚动时收起下拉列表、开关动画和指定时间事件按钮状态均通过检查。
- 未发现乱码、明显遮挡或布局错位。
