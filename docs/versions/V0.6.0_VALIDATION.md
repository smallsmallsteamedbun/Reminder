# Reminder `0.6.0` 验证记录

- 版本：`0.6.0`
- 验证日期：2026-07-29
- 对应更新记录：`docs/versions/VERSION_HISTORY.md`

## 版本范围

- 新增统一通知延迟时长、固定间隔短于统一延迟时的处理策略，以及 Windows 通知横幅显示时长设置。
- 新增事件名称实时搜索、多个关键词的并且匹配，以及最多 5 条最近搜索记录。
- 新增搜索记录置顶、单条删除、全部清空和跨重启恢复。
- 完善设置页左侧标题导航、目标区域定位提示和恢复默认设置确认。
- “全部重启”现在会重启所有已开启固定时间事件，并恢复全部已开启事件。
- 优化搜索框、搜索历史、下拉菜单和应用失去激活时的悬浮菜单收起行为。

## 构建与回归

- Debug 构建通过，0 个警告、0 个错误。
- Release 构建通过，0 个警告、0 个错误。
- 11 项通知设置与事件搜索测试通过，包含统一延迟策略、通知横幅档位、搜索历史、旧状态迁移、非法输入和恢复默认设置。
- 30 项不可提醒状态测试通过，包含全部操作、锁屏、息屏、睡眠、错过汇总和全部暂停单项恢复。
- 17 项持久化测试通过，包含即时保存、受保护状态往返、备份回退、离线恢复和非法界面草稿隔离。

## 已知边界

- Windows 原生通知横幅只提供较短和较长两档显示时长，实际时长仍由 Windows 控制。
- 主题、开机自动启动、静默启动、版本检查、自动更新和正式安装程序尚未实现。
- 自动更新继续等待版本来源和发布方式确定后再实施。

- 项目版本、应用界面版本、需求当前版本、版本目录索引和版本历史已同步为 `0.6.0`。
