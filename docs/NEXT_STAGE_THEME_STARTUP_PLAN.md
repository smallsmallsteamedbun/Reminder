# Reminder 下一阶段：主题与启动行为闭环计划

- 规划日期：2026-07-29
- 基线版本：`0.6.0`
- 计划状态：首轮实现与本机回归已完成
- 关联需求：`docs/REQUIREMENTS.md`
- 关联设置设计：`docs/SETTINGS_PAGE_DESIGN.md`

## 1. 阶段目标

在现有设置页、持久化、托盘和应用重启基础上，完成主题、开机自动启动、静默启动和单实例运行，使 Reminder 的外观与启动行为形成完整闭环。

## 2. 实施范围

### 2.1 主题系统

- 增加“跟随系统”“浅色”“深色”三个主题选项，默认跟随系统。
- 手动选择后立即应用；跟随系统时通过 Windows 状态变化事件更新，不增加轮询。
- 将现有界面颜色整理为可切换的语义资源，覆盖三个页面、全部控件、弹层和独立对话框。
- 深色主题同步处理文字、边框、输入、禁用、危险、成功和焦点状态。
- 分别验证硬件优先渲染与软件渲染兼容模式。

### 2.2 开机自动启动

- 设置页增加开机自动启动开关。
- Windows 模块负责注册、取消注册和读取当前注册状态，UI 不直接操作系统启动项。
- 注册目标使用 Reminder 当前实际可执行文件路径；切换设置后立即保存并更新系统状态。
- 后续 Inno Setup 阶段复用同一启动入口，不在本阶段制作安装程序。

### 2.3 静默启动

- 设置页增加静默启动开关，并在开关说明区域常驻显示“程序启动时以后台模式运行，不显示程序面板”，不使用小问号或悬停提示。
- 静默启动仍完成状态恢复、提醒引擎、Windows 监测、通知、托盘和保存协调器初始化，只跳过主窗口显示。
- 托盘“打开主页”和重复启动入口都能显示并激活已有主窗口。

### 2.4 单实例运行

- 同一用户环境中只运行一个 Reminder 实例。
- 已有实例运行时再次启动程序，不建立第二套事件调度、通知服务或托盘图标。
- 重复启动请求转交给已有实例，并打开、激活主页。
- 软件自身“立即重启”继续使用现有重启流程，不被重复启动保护误拦截。

### 2.5 设置、恢复默认与迁移

- 主题、开机自动启动和静默启动加入类型化设置并进入受保护持久化。
- 旧状态文件迁移时使用默认值：主题跟随系统，开机自动启动关闭，静默启动关闭。
- 恢复默认设置时恢复上述默认值；关闭开机自动启动时同步移除系统启动注册。
- 恢复默认设置继续保留事件、暂停状态和搜索历史。

## 3. 实施顺序

1. 扩展设置模型、状态文档版本与迁移测试。
2. 建立主题资源和主题应用服务，完成全部现有界面的浅色、深色与跟随系统适配。
3. 接入开机自动启动和静默启动服务及设置界面。
4. 建立单实例协调和已有窗口激活通道，并兼容软件自身重启。
5. 接入恢复默认设置和即时保存。
6. 回归托盘、通知、调度、持久化、页面导航、搜索和两种渲染模式。

## 4. 本阶段暂不实现

- 版本联网检查与版本号旁的 `new` 标记；
- 自动下载、校验和覆盖更新；
- Inno Setup 自包含安装、卸载及卸载时保留或删除 `Data`；
- “喝水”和“休息眼睛”两个示例事件的最终预设参数。

## 5. 验收标准

- 三种主题选择、即时切换和跟随系统变化均正确，全部现有界面无乱码、错误颜色、不可读文字或明显裁切。
- 开机自动启动可以启用、关闭并在重启 Windows 后按设置运行，不需要管理员权限。
- 静默启动不显示面板但仍能正常调度、通知、保存并通过托盘打开主页。
- 多次启动 Reminder 始终只保留一个提醒引擎和一个托盘图标；重复启动会激活已有主页。
- 恢复默认设置会恢复跟随系统主题并关闭开机自动启动和静默启动，同时保留事件和搜索历史。
- 旧状态能够兼容迁移；新增设置能够即时保存并在重启后正确恢复。
- Debug、Release、两种渲染模式及既有核心测试全部通过，窗口隐藏后不增加持续轮询或空闲动画。

## 6. 实施结果

- 受保护状态文档已升级为第 5 版，主题、开机自动启动和静默启动均可保存；第 4 版及更早存档按已确认默认值迁移。
- 设置页已经提供外观与启动区域，三种主题可即时切换；跟随系统使用 Windows 用户偏好事件，不增加轮询。
- 浅色、深色语义资源已经覆盖主页、事件页、设置页、下拉菜单、滚动条、提示框与确认框。
- 开机自动启动通过当前用户的 Windows 启动项注册服务实现，不要求管理员权限；注册失败时保留原设置并在设置页显示原因。
- 静默启动会完整初始化提醒、托盘、Windows 监测与保存流程，但不主动显示主窗口。
- 单实例协调已经接入；重复启动只向现有进程发送主页激活请求，不创建第二套提醒引擎或托盘图标。
- 恢复默认设置会恢复跟随系统与硬件优先渲染，并关闭开机自动启动和静默启动；事件、暂停状态与搜索历史继续保留。
- Debug 与 Release 构建均为 0 警告、0 错误；既有 85 项核心回归与新增 8 项主题、启动、迁移和单实例专项测试通过，浅色、深色、即时切换和窄窗口视觉回归通过。
- Windows 重启后的真实开机拉起、系统主题实际切换和托盘人工交互仍建议由用户在普通桌面环境中体验复核；这不改变当前代码闭环。
