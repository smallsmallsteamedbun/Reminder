   - 全部暂停：暂停所有已开启事件的倒计时。
   - 全部恢复：恢复所有已开启事件的倒计时，包括原本被用户单项暂停的已开启事件。
   - 全部重启：重启所有已开启事件的倒计时，包括原本被用户单项暂停的已开启事件。
   - 全部恢复和全部重启只需检查事件是否开启，避免多余计算。
5. 为主页全局按钮增加延迟一秒显示的悬停提示：
   - “全部重启”：`重启所有已开启事件的倒计时`。
   - “全部暂停”：`暂停所有已开启事件的倒计时`。
   - “全部恢复”：`继续所有已开启事件的倒计时`。
   - 暂停/恢复按钮切换后应清除原提示。
6. 把“Windows 通知已就绪”移到界面右下角，作为软件状态提示。通知未就绪时需要标红；鼠标悬停未就绪状态时显示解决办法。用户同时询问通知未就绪通常由什么原因导致。
7. 用户使用 `Win+L` 实测息屏和锁屏策略：重新计时、暂停计时、继续计时但不提醒均正常；继续计时并提醒在锁屏画面仍亮时能提醒，但屏幕变黑后通知不会唤醒屏幕。用户询问普通通知能否唤醒屏幕，并要求依据可实现性处理。
