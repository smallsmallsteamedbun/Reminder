- 拆分为多个输入框后，只有在任一输入框按下 Enter，或者焦点离开整个“固定间隔”表单区域时，才统一换算、自动进位并重排输入框。

- 需要检查非法输入是否可能写入硬盘；非法输入不应进入持久化数据。
- 当界面保持着尚未改正的非法输入时，定时自动保存也不应保存该非法输入。
- 现在实现固定间隔输入框动态拆分功能，并检查、验证非法输入不会被保存。
