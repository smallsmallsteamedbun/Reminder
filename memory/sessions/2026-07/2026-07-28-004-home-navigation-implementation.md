## 摘要

用户在完成备份后正式授权实施已经确认的下一阶段。项目完成“主页、事件、设置”三页面外壳、主页最近事件与圆环计时器、事件页迁移、页面和卡片动画、渲染模式设置、版本化保存以及立即或稍后重启闭环，并完成既有回归、专项界面验证和 Release 资源对照。

## 关键要点

- 主页只读使用现有 `ReminderEventSnapshot`，没有新增事件状态或业务调度器。
- 主页最多展示三个最近事件；关闭和手动暂停固定事件被排除，等待通知操作优先展示，同剩余时间继续按事件列表顺序确定唯一排序。
- 一张、两张和三张卡片使用固定槽位，圆形和卡片可以进入事件页并复用现有定位、高亮。
- 圆环采用已确认的秒、分、时、天和超过 365 天外环，不绘制背景轨道；动画按实际经过时间短时运行，页面隐藏或离开主页时停止。
- 页面快速连续切换只执行最后目标；事件页原有输入、滚动、删除确认、开关动画和全局操作没有回退。
- 渲染模式设置写入状态文档版本 2；版本 1 存档自动补为硬件优先渲染。
- 立即重启先最终保存，新进程携带旧进程 PID 并等待旧进程退出；稍后自行重启只保存设置，不改变当前进程模式。
- 当前设备 Release 完整应用初测：硬件优先主页可见约 `1089 MB` 工作集，软件兼容约 `176 MB`；两种模式隐藏后工作集约 `24 MB`。软件模式稳定 CPU 通常为 `0–0.14%`。

## 变更

- 新增 `System/Settings` 渲染设置模型和服务。
- 持久化改为包含引擎状态与应用设置的复合状态，并保留旧调用兼容入口。
- 新增主页展示模型、倒计时圆环控件、页面导航控制器、主页动画器和渲染模式重启提示框。
- 更新 `App.xaml.cs` 启动、恢复、渲染应用和重启生命周期。
- 更新主页、设置和阶段计划文档，并新增 `docs/versions/NEXT_STAGE_HOME_NAVIGATION_VALIDATION.md`。
- Debug、Release、9 项逻辑、18 项调度、25 项不可提醒、16 项持久化、新阶段专项和界面交互探针全部通过。

## 决策

- 渲染设置与提醒状态继续共用受保护、版本化状态文件，但磁盘文档与运行模型保持分离。
- 页面切换和主页视觉动画抽离为可复用 UI 交互组件，不把动画状态放进提醒业务模型。
- 当前版本号仍为 `0.4.1`；本次实施没有得到版本号更新或发布授权。
