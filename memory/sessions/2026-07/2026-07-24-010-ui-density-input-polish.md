## 摘要

记录了托盘快捷暂停和通知遇到锁屏、睡眠时的后续运行规则，并完成事件名称长度拦截、下拉框滚轮、开关动画、指定时间操作精简、卡片密度调整、息屏与锁屏策略界面占位、输入框光标和底部区域等优化。

## 关键要点

- 托盘“快捷全部暂停”固定采用“直到手动恢复”。
- 已显示但尚未处理的普通通知遇到锁屏或实际睡眠、休眠时按延迟处理。
- 指定时间事件不显示暂停和重启按钮。
- 默认窗口应直接显示完整事件表单，同时保留小窗口横向滚动。
- 本轮息屏和锁屏控件只实现 UI 与会话内选择，不接入 Windows 状态业务。

## 变更

- 更新 `docs/REQUIREMENTS.md`、`docs/REMINDER_LOGIC_DETAILS.md`、`docs/EVENT_FORM_DESIGN.md`、`docs/NEXT_IMPLEMENTATION_PLAN.md` 和 `docs/NEXT_STAGE_AVAILABILITY_PLAN.md`。
- 新增按实际时间运行的轻量开关滑块动画。
- 事件名称超限输入和粘贴会被直接阻止；输入框首次获得焦点时光标移动到末尾。
- 下拉框收起时支持鼠标滚轮切换；事件卡片默认宽度完成压缩和固定位置预留。
- 指定时间事件隐藏重启按钮；第二行加入息屏与锁屏策略的 UI 占位。
- 删除输入应用提示和底部后台运行提示，只保留薄分隔边框。

## 决策

- 指定时间事件不显示重启按钮，替代旧有“保留但置灰”设计（U001）。
- 托盘快捷全部暂停固定为手动恢复；未处理普通通知遇到锁屏或睡眠按延迟处理（U001）。
- 默认窗口无需横向移动，动态表单固定占位，名称超限直接拦截并使用轻量开关动画（U001）。
