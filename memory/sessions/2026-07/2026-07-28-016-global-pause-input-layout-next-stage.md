## 摘要

完成全部暂停期间的逐事件恢复例外：点击单项恢复或成功编辑导致事件取消暂停时，只恢复目标事件，其他事件继续暂停；最后一个受约束事件恢复后自动结束全部暂停。补齐删除事件导致参与者集合缩小时的同一核对，并扩大事件类型、指定时间频率、星期及年/月/日/时/分输入区域。同步修正固定间隔输入框尺寸，归档通知自动消失下拉框、延迟策略、事件搜索历史和恢复默认设置的下一阶段需求。

## 关键要点

- 全部暂停不再只能由一个全局布尔值表达，每条事件分别保存是否仍受本次全部暂停约束。
- 所有取消暂停入口统一经过一个状态转换，编辑和恢复按钮不各自维护重复判断。
- 指定时间事件仍没有单项恢复按钮，但有效编辑可以按既有规则自动开启并取消暂停。
- 全部暂停期间删除事件后也核对剩余参与者；删除最后一个仍暂停的固定或指定时间事件都会自动结束全部暂停。
- 固定间隔天数框完整显示 `365`；小时和分钟编辑框也按最大合法编辑内容复核。
- “固定时间事件”“指定时间事件”、指定时间频率和星期选择框已经扩大，现有选项文字完整显示；默认窗口宽度仍不需要横向滚动。
- 指定时间的年、月、日、时、分输入框进一步加宽；隐藏的星期和日期分量改为不占固定空位，使“仅一次”和各循环频率都能在默认窗口中保持宽松、完整的输入显示。
- 通知自动消失时间以后使用 Windows 实际支持选项的下拉框，不使用任意数值输入。
- 下一阶段包含统一通知延迟、超间隔策略、通知自动消失下拉、事件搜索与最近 5 条历史、恢复默认设置及完整回归；代码继续等待用户备份后授权。
