## 摘要

根据已经确认的首版范围，在用户创建的 WPF 工程中完成 Reminder `0.0.0` 初步简易版本。代码继续保留在单一项目内，并按 `UI`、`Logic`、`Windows`、`System` 划分职责，打通固定间隔事件、倒计时、暂停/恢复/重启、窗口隐藏后台运行、系统托盘和 Windows 通知处理闭环。完成构建、逻辑、真实通知、界面渲染、输入校验、依赖漏洞和资源占用验证，并修正测试中发现的界面与通知问题。

## 关键要点

- 首版只实现固定间隔事件，没有提前显示指定时间、终止次数、设置、主题或持久化等空壳控件。
- 两个初始示例“喝水”和“休息眼睛”默认关闭且可以删除；新增事件默认开启、未暂停、间隔 45 分钟。
- 后台使用单一最近到期一次性计时器，窗口可见时另用 UI 计时器逐秒刷新，窗口隐藏后停止 UI 刷新。
- 通知提供“完成”“延迟”“跳过本次”，按钮不会打开主页。
- 直接设置 Windows 通知到期时间时，自动到期和关闭叉号在当前系统中都会落入 `UserCanceled`。改为应用内 10 秒一次性计时器主动移除通知后，已能把自动消失稳定上报为 `TimedOut`，同时把真实叉号保留为 `UserClosed`。
- Debug 和 Release 均为 0 警告、0 错误；Logic 回归全部通过；NuGet 漏洞检查未发现易受攻击的软件包。
- 正常、窄窗口和非法输入渲染未发现中文乱码或最终排版遮挡；测试中发现的透明根背景和主按钮文字继承问题已经修正。
- 非交互测试桌面无法给出可信的 WPF 硬件渲染内存。软件渲染诊断中窗口显示约 169–205 MB，不能确认低于 160 MB；隐藏约 46.5 MB，20 秒空闲 CPU 采样为 0%。普通桌面可见内存仍需用户复核。
- 本轮没有新增或修改正式产品需求，因此没有改动 `docs/REQUIREMENTS.md`。
- 未执行 Git 提交或远程上传。
